Create ActivityFormView.swift SwiftUI view with create and edit modes:

**State properties:**
- `@State private var name: String` - Activity name input
- `@State private var category: ActivityCategory` - Selected category (default .instrument)
- `@Environment(\.dismiss) var dismiss` - For closing sheet
- Optional `let activity: Activity?` - If non-nil, edit mode; if nil, create mode

**Body structure:**
```
NavigationStack {
  Form {
    Section("Details") {
      TextField("Activity Name", text: $name)
        .textInputAutocapitalization(.words)

      Picker("Category", selection: $category) {
        ForEach(ActivityCategory.allCases) { category in
          Label(category.rawValue, systemImage: category.icon)
            .tag(category)
        }
      }
      .pickerStyle(.menu)
    }
  }
  .navigationTitle(activity == nil ? "New Activity" : "Edit Activity")
  .navigationBarTitleDisplayMode(.inline)
  .toolbar {
    ToolbarItem(placement: .cancellationAction) {
      Button("Cancel") { dismiss() }
    }

    ToolbarItem(placement: .confirmationAction) {
      Button("Save") {
        // TODO: Call viewModel.createActivity or updateActivity
        // This will be wired in Plan 02-03 when ActivityViewModel is created
        dismiss()
      }
      .disabled(name.trimmingCharacters(in: .whitespaces).isEmpty)
    }
  }
}
.onAppear {
  // If editing, populate fields
  if let activity = activity {
    name = activity.name
    category = ActivityCategory(rawValue: activity.category) ?? .other
  }
}
```

Import SwiftUI.

CRITICAL validation:
- Save button disabled when name is empty or whitespace-only
- Use trimmingCharacters(in: .whitespaces).isEmpty to catch "   " as invalid
- Category picker uses .menu style for native iOS feel
- Label shows both icon and text in picker

Note in comment: "// Save action will be connected to ActivityViewModel in Plan 02-03. Form validation ready."
