  <files>Hone/Core/Repositories/ActivityRepository.swift</files>
  <action>
Create ActivityRepositoryProtocol following Phase 1 repository pattern with these exact methods:

**CRUD operations (async/await):**
- `func createActivity(userId: String, activity: Activity) async throws -> Activity` - Uses addDocument(from:) with Codable, returns activity with generated id
- `func updateActivity(userId: String, activity: Activity) async throws` - Uses setData(from:merge:true) for partial updates
- `func deleteActivity(userId: String, activityId: String) async throws` - Uses document.delete()
- `func archiveActivity(userId: String, activityId: String) async throws` - Uses updateData(["archived": true, "updatedAt": ISO8601])
- `func restoreActivity(userId: String, activityId: String) async throws` - Uses updateData(["archived": false, "updatedAt": ISO8601])

**Real-time listener methods (return ListenerRegistration for cleanup):**
- `func listenToActiveActivities(userId: String, completion: @escaping ([Activity]) -> Void) -> ListenerRegistration` - Queries whereField("archived", isEqualTo: false), orders by name
- `func listenToArchivedActivities(userId: String, completion: @escaping ([Activity]) -> Void) -> ListenerRegistration` - Queries whereField("archived", isEqualTo: true), orders by updatedAt descending

Implement ActivityRepository class conforming to protocol:
- Path pattern: db.collection("users").document(userId).collection("activities")
- Use Firestore.firestore() singleton
- Use try doc.data(as: Activity.self) for Codable decoding
- Use compactMap to skip malformed documents
- Always update updatedAt in archive/restore operations using Date().toISO8601String()
- Import Foundation, FirebaseFirestore

Create RepositoryError enum with case missingDocumentId conforming to LocalizedError for consistent error handling across repositories.

CRITICAL: Listener methods return ListenerRegistration (not void) so ViewModels can store handle and call remove() in deinit to prevent memory leaks.
