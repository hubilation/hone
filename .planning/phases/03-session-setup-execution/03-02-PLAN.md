**1. Class structure:**
```swift
import Foundation
import Combine
import FirebaseFirestore

@MainActor
final class SessionViewModel: ObservableObject {
    // MARK: - Published State
    @Published var elapsedTime: TimeInterval = 0
    @Published var sessionState: SessionState = .setup  // Create SessionState enum below
    @Published var currentActivityIndex: Int = 0
    @Published var activities: [SessionActivity] = []
    @Published var currentSession: Session?

    // MARK: - Dependencies
    private let repository: SessionRepositoryProtocol
    private let userId: String

    // MARK: - Timer State (CRITICAL: Date-based, not tick counter)
    private var startTime: Date?  // Store start time as Date for backgrounding survival
    private var pausedElapsedTime: TimeInterval = 0
    private var timerCancellable: AnyCancellable?

    // MARK: - Listener Management
    private var sessionListener: ListenerRegistration?

    // MARK: - Initialization
    nonisolated init(userId: String, repository: SessionRepositoryProtocol = SessionRepository()) {
        self.userId = userId
        self.repository = repository
    }

    deinit {
        timerCancellable?.cancel()
        sessionListener?.remove()
    }
}
```

**3. Session lifecycle methods:**

`func startSession(selectedActivities: [Activity]) async throws`:
- Create Session document with state="active", startTime=now, currentActivityIndex=0
- Call repository.createSession() and store result in currentSession
- Initialize activities array from selectedActivities (convert to SessionActivity with startTime for first, empty for rest)
- Call startTimer()

`func startTimer()`:
- Set startTime = Date()
- Set sessionState = .active
- Create Timer.publish(every: 0.1, on: .main, in: .common) - MUST use .common RunLoop mode (research Pattern 5)
- Use .autoconnect() and .sink with [weak self]
- In sink closure: self.elapsedTime = self.pausedElapsedTime + Date().timeIntervalSince(start)
- Store in timerCancellable

`func pauseTimer() async`:
- Cancel timerCancellable
- Set pausedElapsedTime = elapsedTime (preserve accumulated time)
- Set startTime = nil
- Set sessionState = .paused
- Persist to Firestore: updateSessionState with ["state": "paused", "pausedAt": Date().toISO8601String()]

`func resumeTimer() async`:
- Call startTimer() (creates new Date() startTime)
- Persist to Firestore: updateSessionState with ["state": "active", "pausedAt": NSNull()]

`func skipToNext() async`:
- End current activity: set endTime=now, duration=Int(elapsedTime)
- Save current activity to Firestore: addSessionActivity
- Reset timer state: pausedElapsedTime=0, elapsedTime=0
- Set sessionState = .inBetween
- Call startTimer() to track break time

`func startNextActivity() async`:
- End in-between time: create SessionActivity with isInBetweenTime=true, activityName="Break", duration=Int(elapsedTime)
- Save in-between activity to Firestore: addSessionActivity
- Increment currentActivityIndex
- Check if currentActivityIndex < activities.count:
  - Yes: Reset timer (pausedElapsedTime=0, elapsedTime=0), set sessionState=.active, update activities[currentActivityIndex].startTime=now, call startTimer()
  - No: Call endSession() automatically (session complete)

`func addNote(_ note: String) async`:
- Update activities[currentActivityIndex].notes (append if existing, set if nil)
- Persist to Firestore: save updated SessionActivity

`func removeActivity(_ activity: SessionActivity) async`:
- Remove from activities array
- Persist to Firestore: update Session.activities queue

`func reorderActivities(from: IndexSet, to: Int)`:
- Reorder activities array
- Persist to Firestore: update Session

`func endSession() async`:
- Cancel timerCancellable
- End current activity if not already ended
- Calculate totalDuration from all activities.duration
- Call repository.endSession with endTime=now, totalDuration
- Set sessionState = .ended

`func refreshTimerIfNeeded()`:
- If sessionState == .active && timerCancellable == nil: call startTimer()
- Called from ActiveSessionView.onChange(of: scenePhase) when returning to foreground

**4. Computed properties:**

`var currentActivityName: String`:
- Return activities[currentActivityIndex].activityName or "" if index out of bounds

`var progress: Double`:
- Return Double(currentActivityIndex) / Double(activities.count)

`var upcomingActivities: [SessionActivity]`:
- Return Array(activities[(currentActivityIndex + 1)...]) or [] if at end

`var currentActivityNotes: String?`:
- Return activities[currentActivityIndex].notes

**5. Error handling:**
- Wrap all repository calls in try? for now (error publishing in future)
- Guard against nil currentSession in state update methods

**6. Memory management:**
- Use [weak self] in timer sink closure (prevent retain cycle)
- Cancel timerCancellable in deinit
- Remove sessionListener in deinit

**Critical implementation notes from research:**
- MUST use Timer.publish(on: .main, in: .common) - NOT .default RunLoop mode (freezes during interaction)
- MUST calculate elapsed time from Date difference - NOT increment on timer ticks (survives backgrounding)
- MUST write to Firestore on every state change (pause, skip, note) for crash recovery
- MUST use [weak self] in timer closure (prevent memory leak)
