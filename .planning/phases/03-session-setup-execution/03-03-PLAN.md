Create SessionSetupView for simplified session creation:

**1. View structure:**
```swift
import SwiftUI

struct SessionSetupView: View {
    @StateObject private var activityViewModel: ActivityViewModel
    @StateObject private var sessionViewModel: SessionViewModel
    @State private var selectedActivityIds: Set<String> = []
    @State private var orderedActivities: [Activity] = []
    @State private var isEditMode: EditMode = .inactive
    @State private var navigateToSession = false

    init(userId: String) {
        _activityViewModel = StateObject(wrappedValue: ActivityViewModel(userId: userId))
        _sessionViewModel = StateObject(wrappedValue: SessionViewModel(userId: userId))
    }

    var body: some View {
        NavigationView {
            VStack {
                // Activity selection list
                // Reorder interface (when Edit mode active)
                // Start button
                // NavigationLink to ActiveSessionView
            }
            .navigationTitle("Setup Practice Session")
            .toolbar {
                ToolbarItem(placement: .navigationBarTrailing) {
                    EditButton()
                }
            }
        }
        .onAppear {
            activityViewModel.startListening()
        }
    }
}
```

**2. Activity selection list:**
- Use List with ForEach over activityViewModel.activeActivities
- Each row: HStack with activity name, category icon, checkmark if selected
- onTapGesture toggles selectedActivityIds.insert/remove
- When activity selected, append to orderedActivities if not present
- When activity deselected, remove from orderedActivities
- Display selected count badge: "X activities selected"

**3. Reorder interface:**
- Show orderedActivities in separate List section labeled "Session Order"
- Enable .onMove modifier when isEditMode == .active
- onMove closure: reorder orderedActivities array
- Show "Drag to reorder" hint when Edit mode active
- EditButton in toolbar toggles EditMode

**4. Start Session button:**
- Disabled if selectedActivityIds.isEmpty
- Large, prominent button style (.borderedProminent, .controlSize(.large))
- Label: "Start Practice Session"
- Action:
  ```swift
  Task {
      do {
          try await sessionViewModel.startSession(selectedActivities: orderedActivities)
          navigateToSession = true
      } catch {
          // Show error alert
      }
  }
  ```

**5. Navigation:**
- NavigationLink with isActive binding to navigateToSession
- Destination: ActiveSessionView(viewModel: sessionViewModel)
- Hidden in .background modifier (programmatic navigation)

**6. Empty state:**
- If activityViewModel.activeActivities.isEmpty, show ContentUnavailableView:
  - Label: "No Activities Yet"
  - Description: "Create activities in the Activities tab first"
  - System image: "music.note.list"

**7. Optimization:**
- Tap to select (not EditMode) for faster interaction
- Selected activities automatically added to order list
- Default order: selection order (no manual reorder required)
- Edit mode only needed for changing order

**User flow (3 taps or fewer):**
1. Tap activity 1 (selected, added to queue)
2. Tap activity 2 (selected, added to queue)
3. Tap "Start Practice Session" (session begins)

**Or with reordering (5 taps):**
1-2. Tap activities to select
3. Tap Edit button
4. Drag to reorder
5. Tap "Start Practice Session"
